# Новая философия образования — interactive web lecture

Single-page interactive lecture (Russian) with cinematic background videos, real photographs and background music.

**Stack:** React 19, Vite, Tailwind CSS v4, TypeScript, hosted on Netlify (static, `dist`).

## Run locally
```sh
npm install
npm run dev
```

## Media
- Videos/posters: `public/media/video`, `public/media/img` (Mixkit Free License)
- Portraits: Wikimedia Commons (CC BY / CC BY-SA), poshenloh.com
- Music: add `public/audio/kurmangazy-konil-tolkyny.mp3` (player waits for it)
